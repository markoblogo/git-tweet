Low-noise GitHub milestones to social posts.

git-tweet is a self-hosted release announcer that turns public GitHub releases into predictable posts for X and Bluesky—with one log for every repository and destination.

Conservative release-first rules. No AI. No commit spam. Built for small shipping teams and personal release workflows.
